# Native iOS design previews

Screenshots captured from the SwiftUI app running on the iPhone 16 simulator.
Onboarding, role selection and sign-in use the original TypeScript app's assets.
Password/OTP and dashboard screenshots use fictional demonstration accounts and
school data through Debug-only preview arguments. They are visual checks, not
proof of signed-in backend testing.

- `Onboarding-Connect.png`: first introduction (normal launch)
- `Role-Teacher.png`: swipeable role selector
- `SignIn.png`: school lookup step
- `Password.png`: account preview and password step
- `OTP.png`: six-digit verification step
- `Teacher-Dashboard.png`: teacher home and role tabs
- `Student-Dashboard.png`: student home and role tabs
- `Parent-Dashboard.png`: parent home, child selection and role tabs
